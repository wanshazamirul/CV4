# my-skills - yours, forever

This zone is outside the update system. Nothing here is ever overwritten, deleted, or auto-edited. Your agent reads these like any skill and treats them as **primary**: if one of yours and a bank skill could both fire, yours wins.

## What lives here

- **Skills you bring**: company rituals, personal workflows. Same shape as the bank: one folder per skill with a `SKILL.md` inside (a `name` and a `description` trigger, then the procedure).
- **Skills forged for you**: when a pattern repeats 3+ times and the ladder earns a new skill, `forge` writes it here and registers it (`source: forged`).

## Register yours

Add a row to `registry.md` in this folder. That roster is what the gate checks before generating anything new: dedicated beats generated, always.

## The shape

```
my-skills/
├── registry.md          your roster (the gate reads it)
└── <skill-name>/
    └── SKILL.md         name + description + procedure
```
