# My skills - registry

> Your dedicated skills. Rows here are **primary**: the gate (see `skills/forge/`) checks this file before it ever generates something new. Dedicated wins by default; forge only offers to fold lessons in, and only with your yes.

| skill | source | priority | triggers | notes |
|---|---|---|---|---|

## How a row works

- **skill**: the folder name under `my-skills/`.
- **source**: `dedicated` (you brought it) or `forged` (the ladder made it).
- **priority**: `primary` beats the bank on overlapping triggers.
- **triggers**: what should activate it, a few words.
- **notes**: anything the gate should know.

Empty table = no skills yet. The agent fills rows as you bring or forge skills; updates never touch this file.
