# main - the core

The smallest files in the repo, on purpose. Read in full every session (the manual handles it).

| File | What it holds | Discipline |
|---|---|---|
| `identity-core.md` | who the AI is: name, tone, fundamentals | fill in at BOOT |
| `soul.md` | what it is learning | 40-line cap; real lessons only, added during saves |
| `relationship-memory.md` | who you are: preferences, world, history | grows through use; facts only from the person |
| `current-session.md` | rolling state | last 3 sessions; older lives in `logs/` |
| `hotlist.md` | never-again rules | about 30 lines; `trigger -> action` |
| `skill-sources.txt` | external skill sources you opt into | optional; pinned `npm name@version`; never auto-updated |

**How to use:** read before acting, write during save. **How to extend:** you mostly don't. This folder stays tiny; everything else grows around it. Personal zone: never auto-updated.
