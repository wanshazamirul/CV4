# Recall order, cheapest first

**Problem:** the AI re-debugs solved problems, or presents guesses as facts.

**Solution:** before touching anything familiar, walk the recall order: `main/hotlist.md` -> `memory/index.md` -> `python3 tools/fts.py "<keywords>"` -> `grep -ri library/`. Cite the file, or state "clear". The index gets a one-line row whenever a durable lesson lands.

**Sources:** general practice, seeded at skeleton v0.1.
